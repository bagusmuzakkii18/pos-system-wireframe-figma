# POS System UI/UX Wireframe

## Description
This project is a UI/UX wireframe design for a web-based Point of Sale (POS) system focused on inventory and transaction management.

## Background
This project is inspired by real problems in a small retail business where stock data did not match physical inventory.

## Features (Concept)
- Inventory tracking system
- Stock in/out management
- Simple dashboard for monitoring
- User-friendly interface
